## Rilis mendatang

::note
Perubahan berikut sudah dibuat di source CLI lokal, tetapi belum dirilis ke npm dalam pembaruan ini. Jangan menganggap `npm install -g @ricko-v/l` sudah menyertakannya. Nomor versi berikutnya belum ditetapkan.
::

| Perubahan | Panduan |
| --- | --- |
| `l init` memakai salinan eksklusif saat hard link ditolak di Termux/filesystem lain | [Troubleshooting Termux](/id/referensi/troubleshooting#termux-eacces-permission-denied-link) |
| Profile menolak nama device Windows seperti `con`, `nul`, dan `com1` pada semua OS | [Multi-profile](/id/panduan/multi-profile#menyiapkan-profile) |
| Windows mempertahankan mode executable dari baseline/paket remote saat pull dan push | [Permission executable](/id/panduan/pull-push#windows-dan-permission-executable) |
| Login tetap menunggu callback ketika browser gagal dibuka otomatis | [Login manual melalui URL](/id/mulai/login#browser-tidak-terbuka-otomatis) |

### Status pengujian

Perubahan CLI telah melewati **92 tes lokal pada macOS**, type-check, dan build. Tes mencakup simulasi mode Windows dan fallback hard link; ini bukan pengujian langsung di Windows, Linux, atau Android.

Workflow CI sudah disiapkan untuk Ubuntu, Windows, dan macOS dengan Node.js 22/24, termasuk install, tes, build, bantuan CLI, dan pemeriksaan paket npm. Hasil runner Windows/Linux belum dikonfirmasi dalam pembaruan ini. Login AWS dan deployment sungguhan tidak dijalankan oleh tes tersebut.

Pada Windows, tes file symlink memerlukan hak membuat symlink. Detail untuk kontributor ada dalam `docs/Development.md` di source CLI.

## v2.0.0

Panduan dasar website mengikuti CLI v2.0.0: login browser, `l init`, profile per project, Lambda list/info, serta pull/push satu atau banyak function dengan preview perubahan.

Bagian berlabel **rilis mendatang** menjelaskan perubahan setelah versi tersebut. Setelah rilis berikutnya benar-benar tersedia, catatan ini dan label pada halaman terkait perlu diperbarui bersama.
