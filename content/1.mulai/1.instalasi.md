`l` adalah CLI untuk memelihara kode AWS Lambda dari terminal. Panduan ini mengikuti **@ricko-v/l v2.0.0**.

## Prasyarat

- Node.js **22 atau lebih baru** dan npm.
- Browser untuk login AWS.
- Identitas AWS dengan izin mengakses function yang akan dikelola.
- Lambda function yang sudah ada, dengan deployment berbentuk ZIP untuk pull/push.

## Install dari npm

```sh
npm install -g @ricko-v/l
l --version
l --help
```

Untuk memperbarui instalasi, jalankan kembali `npm install -g @ricko-v/l@latest`.

## Login dan periksa identitas

```sh
l login --profile production
l whoami --profile production
```

Selesaikan AWS Sign-In di browser, lalu tunggu hasil akhir di terminal. Periksa **Account** dan **Identity** sebelum melanjutkan. `production` adalah nama profile lokal; nama ini tidak menentukan account yang dipakai untuk login.

## Buat project

```sh
mkdir billing-lambda
cd billing-lambda
l init --profile production
```

Wizard menanyakan nama project, region resource, dan konfigurasi Lambda. Untuk percobaan pertama, pilih satu function yang sudah ada atau masukkan namanya secara manual. Tinjau JSON, lalu konfirmasi penyimpanan `l.config.json`.

Contoh hasil:

```json [l.config.json]
{
  "version": 1,
  "name": "billing-lambda",
  "region": "ap-southeast-1",
  "profile": "production",
  "lambda": {
    "functionName": "billing-api"
  }
}
```

Ganti nama function dan region dengan target milikmu. Init menyimpan konfigurasi lokal; tidak membuat Lambda baru.

## Ambil kode dan tinjau perubahan

```sh
l lambda info
l pull --dry-run
l pull
```

Kode tersedia di `lambda/billing-api/`. Edit file yang diperlukan dan siapkan hasil build jika project memerlukannya, lalu lihat preview:

```sh
l push --dry-run
```

Saat target dan perubahan sudah sesuai, jalankan:

```sh
l push
```

::warning
Push memperbarui kode **$LATEST** pada function AWS yang sudah ada. Invocation yang menggunakan $LATEST dapat langsung memakai kode baru. Tinjau account, region, dan perubahan sebelum konfirmasi.
::
